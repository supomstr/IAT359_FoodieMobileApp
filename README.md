# Foodie – Restaurant Journal App

Foodie is a cross-platform mobile app built with React Native that allows users to privately document their favorite restaurants.  
Unlike public review platforms, Foodie focuses on personal journaling by letting users save restaurants, add notes, upload photos, and view locations directly on Google Maps.

## Project Overview

Goal:
To create a private restaurant list where users can record and revisit their dining experiences without the influence of public reviews.

Key Features:
- 🔐 User Authentication using Firebase (email/password)
- 🌐 Google Maps + Places API for location search and directions and seeing online reviews
- 💾 Firestore & AsyncStorage for structured and local data storage
- 📸 Camera & Gallery Access with Expo Image Picker
- 🗺️ Live User Location & Route Visualization using Expo Location
- 💬 Personal Notes and Image Attachments per restaurant

## 🧱 Technical Stack

- Framework: React Native (Expo)
- Database: Firebase Firestore
- Authentication: Firebase Auth
- APIs: Google Maps API + Google Places API
- Native Modules: Expo Image Picker, Expo Location
- Local Storage: AsyncStorage
